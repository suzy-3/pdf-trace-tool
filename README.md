# PDFトレースツール

FastAPI・OpenCV・PyMuPDFによる、日本語のスキャンPDF補正・SVG変換アプリです。Sitesは使用しません。

## 起動（Python 3.12 / Windows Python 3.14）

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

ブラウザーで http://127.0.0.1:8000 を開きます。単一ワーカーで起動してください。

## 操作

1. スキャンPDFをアップロードします（20MB以下、暗号化なし、最大100ページ）。
2. ページを選択し、傾き補正・ノイズ除去・線の鮮明化を設定します。
3. 「補正・SVG変換」で元図面と補正後を左右に比較します。
4. 選択中のページを補正PDFまたはSVGでダウンロードします。
5. 「図面を閉じる」で一時保存を削除します。

従来の輪郭変換モードでは、傾きはHough線分から±15度の範囲で推定します。ノイズ除去は非局所平均フィルターと微小連結成分除去、鮮明化はアンシャープマスクと大津の二値化を使用します。レンダリングは最大144dpi・約1200万画素です。SVGは黒線の輪郭をパス化し、穴を保持します。中心線、CAD要素、OCR、寸法認識ではありません。細線や小さい文字は設定により失われる場合があるため、比較画面で確認してください。傾き補正ではページ端が切れる場合があります。

従来モードの出力PDFは選択中の1ページの画像PDFで、元の表示ページ寸法を保持します。元PDFの文字・注釈・レイヤーや複数ページ一括出力は保持しません。

## 一時保存・運用範囲

PDFと処理結果はプロセスメモリーに保存します（最大8文書、1時間）。処理結果のキャッシュは全図面合計128MiBまでで、古い出力から解放します。解放されたページは再変換してください。CAD処理中のマスクやベクトル中間データは権限を制限した一時ディレクトリに保存し、成功・失敗・キャンセル時に削除します。期限切れデータは次のAPIアクセス時に削除されます。再起動で消去されます。URLにはランダムな文書IDを使います。認証・永続保存・複数ワーカー共有は未実装のため、ローカルまたは信頼できる内部環境で使用してください。公開サービス向けの構成ではありません。

依存関係は `requirements-lock.txt` の検証済みバージョンに固定しています。

## テスト

```sh
pip install -r requirements-dev.txt
python -m pytest -q
```

テスト内で2ページのスキャンPDFを生成し、アップロード、ページ表示、補正、SVG/PDF出力、削除、傾き補正精度、ノイズ除去、空白ページ、不正入力、保存上限、有効期限を検証します。GitHub Actionsでも実行します。

API仕様: 起動後の `/docs`。

Chromiumをインストールした環境では、実ブラウザー操作も検証できます。

```sh
python tests/browser_smoke.py
```

既定ではPATH内のChromium、または `python -m playwright install chromium` でインストールしたブラウザーを使用します。別の場所の場合は `CHROMIUM_PATH` を指定してください。アップロード、ページ切替、補正画像表示、PDF/SVGダウンロード、モバイル幅、削除を確認します。

## CAD風清書の品質修正（Issue #5）

「CAD風清書（原画保守ハイブリッド）」またはAPI設定 `{"mode":"cad_clean"}` を使います。
従来の輪郭変換は選択可能です。APIの既定モードは互換性のため `legacy` のままです。

### 形状を壊さない処理

CADモードでは壁・文字・建具に一律のスケルトン化を適用しません。
太壁の帯状領域、接続した壁と交点、文字、窓、建具弧線、薄い線、判断できない領域は
**元のグレースケール画素をSVG/PDFに埋め込んで保持**します。
幾何条件による保護であり、OCRや建築部材の意味認識ではありません。
「清書優先」指定でも破壊的な細線化には戻りません。

長い直線だけを以下の条件でベクトル化します。

- 60pt以上、長さ／幅比12以上の帯状候補を線形回帰で推定します。
- 濃度が安定し、両側の境界・中心・幅が部分区間でも安定していることを確認します。
- 元画素から測った線幅を使用し、端点・平行線間距離を維持します。
- 実際のSVGレンダラーで原画のインク支持が一致し、濃度差1以下・中心位置差0.25px以下の候補だけを採用します。
- 不均一な壁、灰色の弱い線、分岐、曲線、文字等を無理に直線と解釈せず、原画へフォールバックします。

原画と一致する部分だけを再描画するため、見た目が原図のままの領域が多くなる設計です。
整直・自動補完・全図面の完全ベクトル化を保証する機能ではありません。
互換性のためAPIには `line_width` / `join_threshold` / `snap` / `fidelity` を残していますが、
CADモードではこれらによる線幅の上書き・位置の移動を行いません。線幅上書き等の操作項目は画面から除き、原画保持を明記しています。

背景ノイズの処理は形状の変換と分離しています。既定の `noise_strength=0` は原画保持です。
値を上げると、140〜219の灰色を持ち、指定面積以下・縦横2pt以内の孤立点だけを除去します。
黒い文字や句読点は除去しません。灰色の句読点と汚れの意味は自動判別できないため、
薄い文字がある場合は0を使い、除去を有効にした場合は差分を比較してください。
広い汚れや紙面のムラを自動で消して線を損なう処理は実施しません。

### 品質検証と原図保守PDF

同一座標で原画と出力を比較し、インク欠落率・追加率、距離変換による線幅差、
領域単位の連結成分数の差、検証済み直線の位置差を返します。
領域単位の連結成分数は、図面全体の意味的な連結性の保証ではありません。
小領域の欠落率0.5%超・追加率0.2%超・平均線幅差0.25px超・連結成分数の変化が
生じた清書候補は**警告だけで済ませず全体を原画へ戻します**。
ユーザーが明示した点状ノイズ除去は、除去後の原画を基準に候補の品質を検証します。
表示する差分と生の測定値は除去前原画に対する値なので、意図した除去も欠落候補に含みます。

`quality_passed` はこの幾何検査の結果、`review_required` は原画保持が多い／候補破棄時の確認フラグです。
品質検査成功でもCADとしての部材認識や文字認識が完了した意味ではありません。
原画保持の割合、保持領域の画素一致率、測定した線幅、候補検査値もAPIから取得できます。

- 重ね合わせ・不透明度調整、差分（赤: 欠落候補、青: 追加候補）を維持しています。
- 「要確認」表示では橙色で原画保持領域を示します。完全なCAD化でない場合は明示します。
- 「原図保守PDF（未補正）」は処理の成功・失敗によらず取得できます。
  `/api/documents/{id}/pages/{page}/preserved.pdf` は元PDFの選択ページをコピーし、傾き補正や再描画をしません。
- 通常の補正PDFとSVGは、検証済みstrokeと原画保持画像を含むハイブリッド出力です。

傾き補正を指定した場合のみ原画と候補に同一の回転を適用します。
余白を拡張して端切れを避け、PDFはその縮尺と縦横比を保つようページ寸法も拡張します。
厳密な未補正の座標・原PDFの保持が必要な場合は「原図保守PDF」を使ってください。

### 大規模処理・進捗・メモリ

384pxの中心領域と重複領域で候補を判定し、出力は中心領域にクリップします。
グローバル座標を変えず、境界の不明瞭な箇所は元画素を残します。
全ページのスケルトン／Pythonグラフは作りません。
マスク・差分・保持画像の中間領域は一時メモリマップ、ベクトルは一時ファイルに逐次保存します。

既存の144dpi・約1200万画素のレンダリング上限を維持します。
回転後は2000万画素、SVGは64MiB、全図面合計の出力キャッシュは128MiBの安全予算があります。
入力・最終出力のメモリは面積に依存し、無制限・一定メモリの処理ではありません。

画面は `POST .../jobs`（202）で開始し、`GET .../jobs/{job_id}` で段階・概算進捗・領域数を取得します。
従来の同期 `/process` も維持しています。同時処理1件です。
メモリ不足・一時ファイル保存失敗は日本語で案内します。
文書削除時は処理を中止し、出力を復活させません。ジョブの永続復元はありません。

### 利用権を確認した実図面のローカル評価

実図面は提供されていないため、このPRで実図面の品質を確認したとは主張しません。
次の手順で、利用許諾・社内規則・機密性を確認した図面だけをローカル評価してください。
実図面と比較画像には原図の内容が含まれます。リポジトリやActions artifactには保存しないでください。

1. 閲覧・加工の利用権があり、関係者の承認を得た図面を、リポジトリ外の専用フォルダーへ置きます。
2. 同じく非公開の出力先を明示して実行します（外部サービスへの送信はありません）。

```powershell
python tools/evaluate_quality.py --input C:\private\plan.pdf --page 1 --output C:\private\quality-report
```

3. `metrics.json` / `comparison.png` / `review.png` を原図と照合します。
   評価用ROIは `{"room_name": [x0,y0,x1,y1], "wall": [...]}` のJSONにし、
   `--regions C:\private\regions.json` で渡せます。座標はレンダリング後画像のpxです。
4. 壁厚・端点・交点・平行線間隔・小文字・建具を拡大して確認します。
   自動の領域単位検査は寸法精度や部材意味の保証ではありません。
5. 不明箇所は原画保持・未補正PDFを採用し、共有する場合も匿名化と利用権を確認してください。

実図面を指定する場合は `--output` が必須で、非公開の保存先を選べます。
比較の旧コード実行は `--before-revision` で明示した信頼できるリポジトリ履歴だけにしてください。
DXF・OCR・社内サーバー公開はこの品質修正の対象外です。
